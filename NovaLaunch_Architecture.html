graph TD T[獲取當前日期] --> Month[鎖定當前月份 N] Month --> Target[計算累計目標: N * 800,000] Month --> Actual[加總 1月至N月 實際業績] Target --> Gap{缺口分析} Actual --> Gap Gap --> Output[更新戰情室 YTD 指標] classDef ytd fill:#fff,stroke:#1e3a8a,stroke-width:2px; classDef final fill:#1e3a8a,stroke:#1e3a8a,color:#fff; class T,Month,Target,Actual,Gap ytd; class Output final;
💡 決策價值：
  • 即時性：無需手動計算，系統根據系統時間自動校準目標。
  • 精準度：將「全年度目標」細化為「月度累計進度」，提前發現業績滑坡。
